# Product OS Launch Plan

Acme Product OS is preparing a private alpha for small AI-native teams. The first release should focus on persistent project memory, decision capture, and lightweight onboarding for agents. The team wants a simple upload flow where meeting notes, specs, and support conversations become a connected wiki.

Key constraints:

- The first version must run locally.
- Raw uploads must remain immutable.
- Users need to see why a page changed.
- Domain separation is required so product, research, and customer notes do not mix.
