# Retrieval Evaluation

## Summary

Retrieval evaluation measures whether the wiki returns the right evidence for a question, especially when several domains use similar language.

## Key Points

- Track source-grounded answer rate.
- Track wrong-domain retrieval rate.
- Track query artifact reuse.
