# Overview

This demo wiki shows a domain-aware knowledge base for an AI-agent memory product. Raw uploads stay immutable while active synthesis is organized into domains.

## Domains

- [Product OS](domains/product-os/overview.md): product strategy, launch scope, and core system behavior.
- [Customer Feedback](domains/customer-feedback/overview.md): pilot user needs and product-market evidence.
- [AI Research](domains/ai-research/overview.md): retrieval quality, evaluation, and architecture notes.

## Global Knowledge

- [Retrieval Evaluation](global/concepts/retrieval-evaluation.md) is shared across product and research.
