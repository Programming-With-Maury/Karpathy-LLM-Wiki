# Persistent Agent Memory

## Summary

Persistent agent memory means giving AI agents a stable, source-backed knowledge layer they can read across sessions instead of relying on transient chat history.

## Key Points

- It reduces repeated context-setting.
- It keeps decisions connected to source evidence.
- It works best when knowledge is organized by domain.
- It differs from raw chat history because it preserves reusable pages, links, and revision records.
- It gives coding, research, and strategy agents a stable context surface before they act.

- The [launch plan](../sources/product-os-launch-plan.md) names decision capture and agent onboarding as launch priorities.
