# Product OS Launch Plan

## Summary

The launch plan defines a local-first alpha for a domain-aware wiki that gives AI agents persistent project memory.

## Key Points

- The first release focuses on project memory, decision capture, and agent onboarding.
- Raw uploads remain immutable.
- Users need visible revision history and domain separation.
