# Product OS

## Summary

Product OS is a local-first memory layer for AI-native teams. It turns project notes, specs, and decisions into a domain-specific wiki that agents can safely read before acting.

## Key Points

- The launch scope is local-first and alpha-oriented.
- The product must preserve raw sources separately from synthesized pages.
- Revision history and source traceability are first-class requirements.
