# RAG Evaluation Notes

## Summary

The research note compares generic vector search with a curated domain-aware wiki layer.

## Key Points

- Vector search is fast but can drift across projects.
- Domain routing improves precision before retrieval.
- Evaluation should track source-grounded answer rate and wrong-domain retrieval rate.
